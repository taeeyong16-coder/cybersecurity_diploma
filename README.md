# Гібридна система захисту документів (Hybrid Document Protection System)

Це прототип академічного рівня, розроблений для захисту цілісності та автентичності PDF-документів за допомогою поєднання криптографічних цифрових підписів та стеганографічного приховування даних.

## Основні можливості
- **Генерація захищених документів**: Створення PDF з невидимим цифровим підписом.
- **Стеганографія LSB**: Приховування зашифрованого підпису у фоновому зображенні PNG.
- **Цифровий підпис ECDSA**: Використання кривої SECP256R1 для гарантування авторства та цілісності.
- **Шифрування AES-GCM**: Забезпечення конфіденційності та автентичності прихованих даних.
- **Графічний інтерфейс (GUI)**: Розділені робочі процеси для користувача та адміністратора.

## Технологічний стек
- **Мова**: Python 3.x
- **Бібліотеки**: 
  - `cryptography` (Криптографія)
  - `PyMuPDF (fitz)` (Аналіз PDF)
  - `reportlab` (Генерація PDF)
  - `Pillow` (Обробка зображень)
  - `tkinter` (Графічний інтерфейс)
  - `tkcalendar` (Вибір дати)

## Встановлення залежностей
```bash
pip install cryptography Pillow pymupdf reportlab tkcalendar
```

## Основні оновлення
1. **Сучасний GUI**: Оновлений дизайн з використанням теми `clam` та покращеним лейаутом.
2. **Календар**: Додано зручний віджет для вибору дати, що запобігає помилкам форматування.
3. **Підтримка Кирилиці**: Використання Unicode-шрифтів для коректного відображення тексту (ПІБ тощо) у PDF.
4. **Покращена верифікація**: Більш надійний алгоритм вилучення канонічного тексту.
## Структура проекту
- `gui_app.py`: Головний файл застосунку з графічним інтерфейсом.
- `main.py`: Ядро системи, що координує криптографічні та PDF операції.
- `crypto_utils.py`: Модуль для хешування (SHA-256), підписів (ECDSA) та шифрування (AES-GCM).
- `steganography.py`: Реалізація LSB стеганографії.
- `pdf_processor.py`: Генерація та вилучення даних з PDF.

## Як використовувати
1. Запустіть застосунок: `python main.py` або `python gui_app.py`
2. **Вкладка "Користувач"**: Заповніть дані, завантажте підпис (PNG) та натисніть "Згенерувати".
3. **Вкладка "Адміністратор"**: Виберіть згенерований PDF для автоматичної перевірки та архівування.

## Алгоритм перевірки
Система автоматично вилучає фонове зображення, витягує з нього прихований підпис, дешифрує його та порівнює з хешем видимого тексту документа. Результати:
- **VALID**: Документ автентичний.
- **TAMPERED**: Текст або фон було змінено.
- **INVALID**: Помилка вилучення або невірні ключі.
